# Logo Refinement Test App

A prompt-iteration bench for logo refinement. Upload a vector logo (SVG), pick the input type (wordmark, lettermark, symbol, combination mark), then test and iterate on the refinement prompts matched to that type.

- Four draft tiles: Original, Minimal, Precision, Momentum, each with 16px and 32px legibility previews, a star rating and a verdict field
- Eight editable prompt tabs: the master brief, one tuned prompt per input type, and the three variation prompts, each with a version label and change notes
- Draft only: variant tiles are exploration slots, nothing generated here is a production logo
- Client-side only, nothing is saved or sent anywhere

Live: https://rankplanmuse-ops.github.io/logo-refinement-test-app/
